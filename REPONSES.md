# Réponses — TP 3 TravelX

## Exercice 3 — heuristique de Nielsen appliquée

**« Visibilité de l'état du système »** : lorsqu'un départ n'est plus disponible, la carte affiche « Complet » dans la zone d'information, donc l'utilisateur voit tout de suite l'état du départ sans avoir à essayer de réserver.
On peut aussi citer la **« Prévention des erreurs »** : le bouton d'action est désactivé sur un départ complet, il est donc impossible de tenter une réservation impossible.
